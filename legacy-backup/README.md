# Portfolio — Achmad Rafiq Syaddid

Website statis menggunakan HTML, CSS, dan JavaScript tanpa framework.

## Menjalankan

Buka `index.html` langsung di browser atau jalankan server lokal sederhana:

```bash
python -m http.server 8000
```

Lalu buka `http://localhost:8000`.

## File

- `index.html` — struktur dan konten halaman.
- `styles.css` — sistem visual Neubrutalism dan responsive layout.
- `script.js` — menu mobile, navigasi aktif, tahun footer, dan salin email.

## Catatan desain

Panel warna pada daftar proyek adalah ilustrasi CSS untuk memberi identitas tiap entri. Panel tersebut bukan screenshot aplikasi. Saat screenshot asli tersedia, tampilan panel dapat diganti dengan gambar proyek yang sebenarnya.

Email, GitHub, dan Instagram dihubungkan. URL repository aplikasi cek cuaca belum dipastikan, sehingga tautannya mengarah ke daftar repository GitHub, bukan URL repository yang ditebak.
